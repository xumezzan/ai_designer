# Haute Editorial: генератор и рендерер

Промпт владельца внедрён в рабочий `/api/generate`. Новый запрос создаёт одно
приглашение и сохраняет полную `Theme.designSpec`, которую читает рендерер.
Старые приглашения без этого поля продолжают использовать прежние композиции.

Исходное задание сохранено в `user-prompt.txt`. Рабочая версия находится в
`lib/ai/prompts/hauteDesign.ts`: учтено подтверждённое владельцем правило
антиповтора **сочетания архетипа, видимой маски и семейства тона бумаги**.
Отдельный архетип может повторяться.

## Создание

1. В пользовательский контекст модели передаются бриф, референсы, сведения о
   доступных фото, фактах события и поддерживаемых компонентах. Сведения о
   предыдущих дизайнах содержат только визуальные решения, без имён, адресов,
   фото, заголовков и художественных промптов других проектов.
2. Модель вызывает `emit_design_series` с транспортным JSON
   `{ facts, design_spec, photos }`. `design_spec` точно соответствует объекту
   из задания. Обёртка сохраняет действующий механизм извлечения подтверждённых
   фактов и размещения фотографий. Вся обёртка и вложенные объекты валидируются.
3. Компилятор связывает спецификацию с реальными шрифтами, цветами, материалами
   и композициями. Он восстанавливает контраст текста минимум до 4.5:1,
   сохраняет значения в самой спецификации и соблюдает защищённые обрезки фото.
   Закреплённое владельцем расположение фото канонизируется до сравнения.
4. До создания изображения проверяются последние 12 доступных различных
   визуальных решений, по времени сохранения версий. Повтор указанного
   сочетания запрещён. Дополнительно нужны минимум два видимых отличия.
   Соседний HEX, новые имена и скрытая печать не обходят проверку.
   Некорректный результат получает одну попытку исправления; затем запрос
   завершается ошибкой, сохраняя предыдущие приглашения.
5. Изображение создаётся, только если включена его генерация в студии **и**
   `graphics_generation.needed=true`. Иначе используются оригинальные SVG
   и живая типографика. Новая графика создаётся одним запросом. Фоновая сцена,
   иллюстрация в паспарту и свободный ботанический мотив размещаются по-разному.
6. Сохраняются спецификация, факты, фотографии и метаданные графики; остаются
   действующие редактор, версии, автоматический QA и обработчики ответа гостя.

История ограничивает повтор среди недавних дизайнов, а не доказывает глобальную
уникальность каждого изображения или каждой возможной композиции.

## Поддерживаемые решения

| Архетип | Компонент | Композиция |
| --- | --- | --- |
| `ARCH_EDITORIAL` | `arch` | Высокая арочная открытка |
| `RAW_ASYMMETRIC` | `poster` | Асимметричный разворот и вертикальная дата |
| `BOTANICAL_PLATE` | `botanical` | Ботанический лист с музейным паспарту |
| `RETRO_MONOGRAM` | `folio` | Конверт, инициалы и сургуч |
| `MINIMALIST_TYPOGRAPHIC` | `letter` | Типографическая сетка и тонкие правила |

Реально отрисовываются все зарегистрированные варианты выравнивания, рамки,
бумаги, маски, тонирования, сургуча и фольговых линий. Программа имеет три
представления; палитра — круги, тканевые карточки или капсулы; RSVP — классический
бланк, нижний лист или letterpress. Защищённые лица/руки, не помещающиеся в
выбранный силуэт, автоматически получают прямоугольное паспарту.

Антиква: Cormorant Garamond / Playfair Display, нормальное и настоящее курсивное
начертания. Гротеск: Montserrat / Jost. Это локальные WOFF2 Google Fonts с
лицензиями и контрольными суммами; гостю не нужен запрос к внешнему серверу
шрифтов. Для отсутствующих в Jost узбекских символов используется Montserrat.
Cinzel не рекламируется как поддерживаемый шрифт этой библиотеки.

Трекинг принимается как ограниченный токен и переводится в CSS-переменную;
произвольные CSS-классы, URL, чистый белый/чёрный и неизвестные IDs отвергаются.
Курсивные акценты сопоставляются с живым текстом безопасно, без HTML-инъекции.

## Доработки и примеры

Refinement принимает строгую частичную `designSpec`. Прежние правки палитры,
фольги и трекинга переводятся в её поля. Не поддерживаемые этим рендерером
эффекты возвращают явную ошибку. Размещение существующей графики можно изменить
без повторной генерации: байты, SHA и исходный тип изображения сохраняются.

`/editorial` и `/editorial/{arch,poster,botanical,folio,letter}` показывают пять
**авторских контрольных примеров**, а не результаты вызова платной модели.
Их JSON находится в `lib/design/fixtures.json`.

`scripts/qa-editorial.mjs` проверяет 15 мобильных сочетаний (320/390/430 px),
полную вертикальную страницу, локальные шрифты, шум, курсив, палитру, календарь,
RSVP с сохранением значений при возврате и исходным POST, отсутствие JavaScript,
reduced motion и десктоп 1440 px. Ответ формы перехватывается локально.
Снимки и `qa-report.json` находятся рядом с этим документом. Unit/integration
тесты проверяют модельный транспорт с моками, схемы, компилятор, повтор дизайнов,
сохранение версии и неизменность метаданных графики. Платные вызовы для проверки
не выполнялись.
