# Organic Paper

Переработанный бумажный стиль нативных приглашений. Предпросмотр:
`/preview/demo/letter/2?embed=1`. Новая демонстрационная ревизия включает плавный
reveal; исходный JSON v1 сохранён. Реальные данные, получатели RSVP и фотографии
демонстрации не изменены.

## Дизайн и подключение

- `app/organic-paper.css`: мобильная композиция, льняной фон, арочная открытка
  с подложкой и внутренней рамкой, тонкая программа вечера, круглые образцы
  цветов, ответный бланк и декоративная сургучная печать.
- `components/craft/PaperBotanical.tsx`: оригинальная декоративная SVG-графика.
- `public/textures/organic-paper.svg`: тайловый шум, opacity 0.05,
  `pointer-events: none`; текст остаётся HTML.
- `app/organic-fonts.css` и `public/font-assets/organic`: локальные WOFF2
  Montserrat 400/500 и Cormorant Garamond Italic 300 из Google Fonts. Обычный
  Cormorant 300 уже поставляется проектом. Файлы включают кириллицу и расширенную
  латиницу; глифы U+02BB/U+02BC проверены в новых латинских файлах.
- CSS импортируется после прежних стилей в маршрутах предпросмотра и материалов.
  Класс `organic-paper` назначается только явной композиции `organic-paper`.
  Letter, poster, folio, arch и botanical сохраняют собственные палитры,
  типографику и материалы и не получают общий арочный бумажный стиль.
  Авторские фотоистории, специальные материалы и сгенерированная графика
  продолжают использовать свои специализированные рендереры.

Визуальные токены бумажного стиля живут в `.invitation-experience`. Структура
контента, поля редактора `data-studio-field`, порядок разделов, размещение и
защищённые кадрирования фотографий, состояния RSVP/палитры, ссылки календаря,
персонализация и адресаты сохранены. Названия оттенков описывают ближайший цвет
из небольшой локализованной палитры; точный HEX остаётся в доступной подписи.

RSVP использует прежний нативный POST: `name`, `attendance=yes`, опционально
`guests`. Для двух кнопок добавлены разные React keys: повторный переход со
шага имени больше не превращает тот же click в отправку формы. Значения
сохраняются при возврате. Серверный HTML содержит полную форму; reveal скрывает
элементы только после регистрации наблюдателя, а reduced motion отключает движение.

## Проверка

`qa-report.json` и PNG рядом фиксируют браузерную проверку. Скрипт создаёт и
удаляет временный проект, перехватывает тестовый POST локально и не обращается
к внешнему получателю или генератору.

```sh
STUDIO_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
STUDIO_CHROME='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' \
STUDIO_QA_URL=http://127.0.0.1:3149 node scripts/qa-organic-paper.mjs
```

Проверяются шесть композиций на 320/390/430px, полный экран 390×844, десктоп
1440px, календарь, палитра, валидация и сохранение значений RSVP, состав POST,
открытие конверта, reveal, reduced motion и страница без JavaScript.

Шрифты можно заново подготовить командой
`node scripts/prepare-organic-fonts.mjs`. Лицензии OFL, URL источников и SHA-256
сохранены рядом с файлами; обычная загрузка страницы и сборка не требуют Google.
