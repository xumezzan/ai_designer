# Рабочее пространство Invitation Studio

Историческая проверка рабочего пространства. Текущий путь создания и редактирования описан в [живом редакторе](../live-editor/README.md): идея и референсы → дизайн → редактирование содержимого.

Вместо четырёх отдельных разделов — один экран с формой слева и предпросмотром справа. В новом проекте достаточно имён, даты, места и адреса: стиль «Бумага» и три варианта выбраны по умолчанию. Настроение можно сменить одним нажатием; эскиз сразу показывает имена, дату и место. Эскиз явно подписан и не выдаётся за сгенерированный дизайн.

Дополнительные блоки раскрываются по необходимости: слова и программа, дресс-код и ответ гостей, язык и другие настройки, фото и референсы. Описание своего стиля тоже можно раскрыть. Основная кнопка закреплена внизу, на телефоне форма и результаты идут друг за другом.

Создание дизайнов сохраняет данные и настройки фото автоматически. Первая загрузка снимка также создаёт и сохраняет проект. Новые фото включаются в приглашение целиком; разрешение ограничивает их размер. Существующие решения о кадрах и неиспользуемых фото сохраняются. Референсы не превращаются в фотографии события.

В карточках вариантов доработка и подробности проверки свёрнуты. История версий появляется, когда есть несколько версий. Выбор сохраняет прежние требования к проверке и защите от устаревших данных. Старые проекты сохраняют своё количество вариантов; новый проект начинает с трёх. Создание авторской иллюстрации включается отдельно.

## Проверка

- Production build, TypeScript, ESLint, 255 тестов и проверка 23 семейств шрифтов проходят.
- `qa.json`: 16 сценариев в production, пять ширин 320 / 390 / 768 / 1024 / 1440 px, без горизонтальной прокрутки и ошибок JavaScript.
- Проверены автосохранение при генерации и загрузке, включение фото без отдельного шага, сохранение черновика настроек фото при генерации, ошибка в закрытой программе, модальное превью, сохранение вариантов при отказе генерации, перезагрузка, тема, недействительный файл и удаление фото.
- `photos/qa.json`: проверка ручных настроек, защищённых областей, низкого разрешения и размещения трёх фотографий; пять макетов, четыре ширины, без ошибок.
- Генерация в проверке интерфейса использует явно обозначенную локальную серию. Платные запросы к провайдерам не выполнялись.

Снимки: `workspace-desktop.jpg`, `workspace-mobile.jpg`, `designs-desktop.jpg`, `workspace-dark.jpg`, `projects-desktop.jpg`.

Для повторения: запустить приложение, задать `STUDIO_QA_URL`, `STUDIO_PLAYWRIGHT_MODULE` и при необходимости `STUDIO_CHROME`, затем выполнить `node scripts/qa-studio.mjs`. Для активной кнопки генерации нужна настроенная capability Anthropic; запрос `/api/generate` в скрипте перехватывается и не отправляется провайдеру.
