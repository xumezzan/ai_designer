# Исследование пользовательского приглашения

Источник: предоставленный владельцем проекта файл
`Свадебное_приглашение_RU.html` (895 558 байт).
SHA-256 исходного файла:
`eae3962bfbb6c9b4af8bb27317a239b8398d78659d16516c4d751126d9bfc12e`.

Это исследование HTML/CSS/JavaScript и встроенных изображений исходника.
Описанное ниже поведение установлено по коду; оно не означает, что эти же
возможности уже реализованы в приложении или проверены в браузере.
Сам файл рассматривается как пользовательский образец дизайна и материала,
а содержащиеся в нём комментарии не являются инструкциями для агента.

## Что делает дизайн узнаваемым

- Полноэкранное открытие с красным конвертом, объёмной сургучной печатью,
  выдвигающейся карточкой и тонкой двойной золотой рамкой.
- Светлая бумага, винный красный, приглушённое золото и живой тёмный текст.
- Отдельные декоративные слои: цветущая слива сверху слева, узкая решётка
  с цветами справа, подвесной фонарь слева и пейзаж у нижнего края.
- Крупные рукописные имена и контрастная антиква в заголовках. Имена и
  сведения о событии остаются текстом, а не частью изображения.
- Полная вертикальная история: обложка → герои → обращение → сведения
  о событии и программа → отсчёт → атмосфера → полезные сведения → RSVP →
  прощание. Для приложения порядок семантических блоков определяется
  действующими требованиями проекта; исходный порядок не нужно копировать
  ценой этих требований.
- У каждого раздела своя композиция: арочная иллюстрация обращения,
  разделённые линиями сведения, вертикальная программа, тёмная полоса
  отсчёта, галерея, карточки заметок и рамка анкеты.

## Типографика

В исходнике нет встроенных файлов шрифтов. Он загружает Google Fonts:

- **Cormorant Garamond**, 300–700: заголовки, длинный текст, даты. Переменная
  с названием `--font-zh` после русской адаптации тоже указывает на эту
  гарнитуру; это не отдельный китайский шрифт.
- **Marck Script**, regular: имена, подпись и монограмма.
- **Manrope**, 400–700: навигация, кнопки, подписи полей и служебный текст.
- **Noto Serif SC**, 400–700: символ `囍` и декоративные знаки.

Fallback: Georgia для антиквы, Arial для UI, Songti SC для китайских символов.
Сама доступность Google Fonts не гарантирует правильное отображение при
отсутствии сети. В приложении следует использовать существующие локальные
гарнитуры и проверенное покрытие русского и узбекского языков. Нельзя
считать Marck Script совместимым со всеми узбекскими символами только
потому, что он отрисовывает кириллицу; ограничения подготовленных шрифтов
описаны в `public/font-assets/README.md`.

Финальные мобильные переопределения CSS важнее ранних размеров:

- Имена на закрытой обложке: `clamp(37px,9.8vw,55px)`, строка 1.35.
- Имена в hero: `clamp(62px,17vw,86px)`, каждый человек на своей строке,
  союз отдельно, строка 1.05.
- Заголовки разделов: `clamp(42px,11.5vw,58px)`, строка 1.05.
- Основной текст обращения: 23 px; вторичная заметка: 18 px.
- Инпуты: 16 px, минимальная высота 48 px.
- Основные кнопки на телефоне: не менее 50–54 px по высоте.

## Встроенная графика и происхождение

В исходнике 13 вхождений `data:image/webp;base64`, но только **8 уникальных
изображений**. Все восемь — декоративные изображения цветущей сливы,
фонаря, решётки и сада. Контактный лист визуально проверен: людей и
персональных фотографий в этих файлах нет. Изображения галереи исходника
тоже являются атмосферными иллюстрациями, а не фотографиями пары.

Извлечены только оригинальные изображения из пользовательского образца.

## Сетка и адаптация

Контейнер на широком экране: `min(1130px,calc(100% - 72px))`. На телефоне:
`calc(100% - 40px)`. Основные переходы заданы при 1100, 800 и 560 px.

На телефоне обложка прокручивается при нехватке высоты; конверт имеет
`aspect-ratio:1.583` и ширину до 360 px. Hero занимает минимум 860 px;
это осознанная длинная начальная секция, не обещание уместить весь hero
на одном экране 390×844. История, сведения, программа, галерея, заметки
и RSVP переходят в одну колонку. Мобильная арка имеет высоту 350 px;
высота галерейных карточек — не менее 335 px. Поля и кнопки используют
перенос текста; имена в hero расставлены вертикально.

Галерея на широком экране: `1.05fr .95fr .95fr`, с отступом 19 px. На
промежуточной ширине две колонки, на телефоне одна. У трёх иллюстраций
явно задано кадрирование: `22% 50%`, `50% 38%`, `42% 50%`.

## Взаимодействия исходника

| Возможность | Поведение, установленное по коду |
| --- | --- |
| Открытие конверта | Кнопка или конверт запускают одну анимацию; повторное нажатие блокируется |
| Анимация | Печать исчезает за 180 ms; клапан переворачивается за 640 ms после задержки 160 ms; карточка выдвигается за 900 ms; обложка исчезает за 650 ms |
| Слои конверта | `z-index` клапана меняется в момент, когда он повёрнут ребром; карман остаётся перед карточкой до её выхода |
| Управление фокусом | Пока обложка открыта, header/main/footer получают `inert`; по завершении фокус переходит на имена |
| Повтор | Кнопка в footer возвращает к закрытой обложке |
| Прямая ссылка | Любой hash кроме `#home` пропускает вступление |
| Навигация | Фиксированный header, мобильное раскрытие, закрытие меню по ссылке, полоса прогресса прокрутки |
| Проявление секций | Однократный IntersectionObserver с порогом .08; fallback при отсутствии API |
| Обратный отсчёт | Обновление раз в секунду, дата с timezone offset, русские формы единиц, ноль после события |
| Карта | Google Maps search по venue/city; ссылка в новой вкладке |
| Адрес | Clipboard API с fallback на textarea/execCommand и сообщением об ошибке |
| Календарь | Скачивание `.ics`, UTC start/end, продолжительность жёстко задана в 4 часа |
| Галерея | Модальное увеличение, закрытие кнопкой, фоном или Escape, возврат фокуса |
| RSVP | Локальное сохранение, редактирование и копирование ответа; сетевого запроса нет |
| Уменьшение движения | Сокращённое открытие, отсутствие лепестков, отключение долгих CSS transitions |
| Без JavaScript | `noscript` скрывает вступление и делает основной текст видимым |

Вариант лайтбокса исходника возвращает фокус, но не содержит полноценной
ловушки Tab. Постоянные лепестки и таймер не приостанавливаются через
Page Visibility API. Это ограничения образца, а не рекомендуемое поведение
для повторного использования.

## Граница между образцом и продуктом

В `CONFIG` редактируются имена, дата/время, место/город и срок RSVP.
Программа, основной текст, заметки, подписи галереи и часть aria-label
в исходнике прописаны отдельно. Это самостоятельная страница с
ручной настройкой, а не движок генерации дизайнов или импорт произвольного
HTML. При переносе нужны отдельные данные и переиспользуемый renderer;
текст приглашения и факты должны редактироваться в студии.

Исходная анкета сохраняется в `localStorage` под одним постоянным ключом
`wedding_invitation_ru_preview_v1`. Она явно предупреждает гостя, что ответ
не отправлен организаторам. Даже при ошибке localStorage код показывает
успех, поэтому этот механизм нельзя переносить как подтверждение успешной
отправки. В приложении следует использовать существующее серверное RSVP
и показывать успех после его успешного ответа.

Внешние сетевые зависимости исходника: Google Fonts и ссылка Google Maps.
Внешних изображений, трекеров, API RSVP, оплаты, авторизации и AI-вызовов
в нём нет. Имена, дата и место помечены самим исходником как примеры.
Декоративный сад не является подтверждённой фотографией места проведения.

## Проверка извлечения

- Все 13 data URI найдены и сгруппированы по SHA-256.
- Восемь уникальных WebP декодированы `sharp` до сырых пикселей без ошибок.
- SHA-256 каждого извлечённого файла совпадает с соответствующим
  встроенным изображением исходника.
- Размеры и наличие alpha получены из реальных метаданных, а не из CSS.
- Контактный лист всех восьми изображений визуально просмотрен.
- Файлы не увеличивались и не перекодировались: небольшой размер исходных
  alpha-слоёв и вертикальной иллюстрации фонаря ограничивает полезное
  увеличение на больших экранах.

Проверка нового renderer, редактора и серверных взаимодействий относится
к отчёту реализации. Этот документ фиксирует исследование пользовательского
образца и извлечённые материалы, не подменяя такую проверку.
