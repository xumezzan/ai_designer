# Создание из идеи и живой редактор

Новый проект начинается с одного описания: дизайн, атмосфера, цвета, материалы и детали. Референсы доступны сразу. Имена, дату, место и адрес можно заполнить после создания дизайна; они больше не блокируют сохранение, загрузку или генерацию. Количество вариантов и авторская иллюстрация остаются дополнительными настройками.

После генерации открывается один дизайн на холсте. Слева — «Текст и блоки», «Дизайн», «Фото» и «Варианты». Имена, заголовок, обращение и место можно править прямо в приглашении. Остальные данные редактируются в панели. Предпросмотр обновляется через локальный мост без перезагрузки iframe при наборе текста. Дата и место не подставляются автоматически: календарь, отсчёт и раздел места отсутствуют, пока их не добавили. Разделы, заполненные после генерации, добавляются перед завершением даже в ранее минимальной композиции.

Изменения в существующем проекте сохраняются после короткой паузы в наборе. Сохранение не блокирует ввод и не заменяет более свежий текст ответом предыдущего запроса. Ошибки сохраняют локальный черновик и показываются пользователю. Кнопка сохранения позволяет повторить запрос. Отмена и повтор доступны для текста и данных, включая дату. Фотографии сохраняются через отдельный механизм; их загрузка не отменяется историей текста.

Режим холста использует существующий мобильный renderer при ширине 390 px. Доступен desktop preview. Фото и их настройка обновляют холст после сохранения. Дизайн можно доработать описанием через существующую генерацию новой версии; свободное перемещение произвольных объектов и универсальная система слоёв пока не реализованы. Предпросмотр для гостей читает сохранённые данные при открытии; публикация и синхронизация уже открытой гостевой страницы остаются отдельными функциями.

Автоматические проверки сохраняют прежние требования к выбору дизайна. Редактор отправляет через мост только разрешённые текстовые поля и принимает сообщения от своего iframe и origin. Картинки и идентификаторы проекта через текстовое редактирование изменить нельзя.

## Проверка

`npm run typecheck`, `npm run lint`, `npm test` (312 тестов), `npm run build` проходят. Production browser QA прошёл 15 сценариев при ширинах 320 / 390 / 430 / 768 / 1440 px: описание и референсы до данных, создание дизайна без фактов, живые правки в панели и на холсте, добавление разделов, очистка даты, автосохранение при продолжении набора, отмена/повтор, перезагрузка, переключение дизайна, прежние ограничения проверки, добавление и удаление фото после генерации, гостевая страница без JavaScript. Ошибок JavaScript и горизонтальной прокрутки нет. Полные результаты — `qa.json`; снимки первого экрана и полной мобильной страницы — `invitation-mobile-*`.

`STUDIO_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs STUDIO_CHROME=/absolute/path/to/chrome STUDIO_QA_URL=http://127.0.0.1:3147 node scripts/qa-live-editor.mjs`.

Browser QA использует реальное сохранение файлов и загрузку изображений, но перехватывает генерацию локальной серией. Платные запросы не выполняются. Результаты и снимки записываются в эту папку; тестовые проекты удаляются после проверки.
