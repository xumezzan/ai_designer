# Independent art directions

Bold briefs can request `exploration` mode with an independent palette and typeface for every variant. Legacy series remain cohesive. Only these two bounded style fields may vary; shared artwork, materials, motion, source-photo quality and protected crops keep the same validation. Canonical identities are revalidated before saving, and every enabled photograph must still appear exactly once.

Three new authored compositions are available: `duet`, `ribbon` and `imprint`. Their local SVG geometry uses event hosts and date as a stable seed. The seal uses actual initials. Graphics and lettering occupy separate reserved regions, including mobile screens; decorative layers are hidden from assistive technology and do not intercept input. Generated image layouts retain their original rendering path. Headline scale and tracking remain adjustable through the bounded typography tokens.

The typefaces are genuinely different: Unbounded, Prata and Tenor Sans. Their licensed, pinned Google Fonts sources are subset locally into WOFF2. Coverage and fallback metrics are measured; incomplete extended Latin coverage is recorded rather than assumed. Prata and Tenor Sans are rejected for unsupported Uzbek display text. Normal build and runtime require no network font service.

Validation: 290 unit/integration tests, ESLint, TypeScript and the production build pass. The [browser report](./report.json) covers three full invitations, four viewport widths, long Cyrillic names, no JavaScript and separate text/art bounds. Final production measurements cover all three saved directions at 320/390/1024/1440px. Pixel contrast, font loading, clipping, photo crop, tap targets, LCP and CLS checks have no errors. Existing source-resolution and typography warnings remain recorded. No paid AI generation or vision evaluation was called; the authored examples use explicit `codex-authored` provenance.

The previous customer series, original photo files and asset plan were preserved. Only the customer's selected art brief and the current generation pointer changed. Personal screenshots are stored outside the repository.
