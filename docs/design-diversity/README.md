# Различимые новые приглашения

Organic Paper — отдельная зарегистрированная композиция, а не общий стиль
рендерера. Существующий предпросмотр `/preview/demo/letter/2` сохранён; его JSON
теперь явно выбирает `composition: "organic-paper"`. Остальные композиции
используют свои исходные материалы, шрифты, геометрию и цветовые токены.

При новой генерации API читает до 12 различных недавних дизайнов из локальных
проектов, приоритетно из текущего проекта. Учитываются и старые серии, которые
уже не выбраны в редакторе. Память ограничена и содержит только решения
рендерера: композицию, типографику, материал, расположение фокуса/фотографий и
графический язык. Имена, адреса, тексты, ссылки и референсы других событий
в запрос модели не передаются.

Новая конфигурация должна отличаться от каждой записи как минимум по двум
из этих признаков. Перекраска, новый текст, другая анимация, идентификаторы фото
и неиспользуемые декоративные поля не засчитываются. Такие же проверки
применяются между направлениями в явно запрошенной exploration-серии.
Уточнение принятого дизайна через refine не подчиняется этой проверке.

Для создаваемой графики сравнивается также словарь исходного описания мотива:
цвета и общие рекламные эпитеты удаляются, небольшие перефразировки не считаются
новым графическим языком. Описание берётся из локальной метаинформации рисунка
и не передаётся другим проектам. В контекст модели уходит только стратегия
scene/accent; сравнение словаря выполняется локально до запроса изображения.

Проверка выполняется до запроса нового bitmap. Повтор вызывает одну
корректирующую попытку в существующем цикле генерации; второй повтор завершает
запрос с понятной ошибкой и не заменяет предыдущую серию. Сам бриф и референсы
продолжают определять допустимое направление; шаблоны не чередуются случайно.

Это проверка различимости поддерживаемых решений рендерера. Она не сравнивает
пиксели всех возможных изображений и не утверждает мировую уникальность дизайна.
История ограничена последними 12 различимыми решениями.

Код: `lib/generation/diversity.ts`, `lib/generation/history.ts`,
`lib/ai/generateSeries.ts`, `lib/ai/prompts/generateSeries.ts`.

Тесты проверяют изоляцию стилей, отклонение перекраски, требование двух
признаков, память старых серий и отсутствие чужих фактов, корректирующую
попытку и отказ до платного вызова создания изображения. Мобильные снимки
различимых композиций находятся в `docs/organic-paper/`.
