# Personal wedding websites

The reference study covered the WedWed catalog and three live examples: **Однажды**, **Маленькое счастье** and **Как в кино**. Their useful design principles are personal photography, expressive names, an invitation opening, a real month calendar, varied section composition, and practical guest details. The implementation uses original layouts and the customer's existing photo and facts. No reference photographs, text, scripts or template assets were copied.

Three native compositions are registered: `keepsake` (a mounted photo album), `vow` (romantic handwriting with a centred photograph), and `editorial-story` (a magazine opening). Each renders the complete story, a calendar in the event timezone, downloadable calendar links, a contrasting countdown band, venue details, and populated timeline, dress code and RSVP sections. Optional sections appear only with actual host data. The opening greeting photo loads eagerly while retaining its existing crop and source-resolution rules; usable photos do not become full-photo heroes. Photographs render exactly once. Stories reject incompatible artwork and unsupported section order.

The studio now offers **Свадебная история** as its first direction. Generation receives the supported layout recipes and strict factual/photo requirements. Existing art compositions remain available. `handwritten` uses locally vendored Marck Script from the pinned, hash-verified Google Fonts source under SIL OFL. Measured missing Uzbek modifier apostrophes exclude this display set from Uzbek selection. No network font service is required at runtime.

Validation: 301 tests, TypeScript, ESLint and the production build pass. Three complete browser reports cover pixel contrast, typography, taps, photo crop/resolution, motion, LCP and CLS. There are no failed/error checks. The [report](./report.json) also records 24 production regression cases: 320/390/1024/1440px, long Cyrillic names, no JavaScript, all optional sections, and cover opening with keyboard focus. Conservative caption-overlap and short-heading typography warnings are retained with visual review. Personal screenshots and full private QA artifacts remain outside the repository.

The local examples use explicit `codex-authored` provenance; paid generation and vision were not called. Original event facts, photo files, crop plan, all earlier versions and approval were preserved. Only the selected design brief and current series changed; the previous series metadata was archived locally.
