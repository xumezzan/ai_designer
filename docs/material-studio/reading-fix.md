# Читаемость поздравления и финала

Исправление относится к текущим опубликованным страницам на локальном порту
4315, включая [поздравление Лейле](http://127.0.0.1:4315/i/invite-26857eb74a12d833ff3ea320).
Новая генерация изображений или текста не запускалась.

## Причины

1. Общий `Greeting` унаследовал desktop-сетку приглашения: заголовок слева,
   длинное центрированное поздравление в узкой правой колонке. Это не подходило
   личному письму и оставляло большую пустую область.
2. Стиль immersive делал финальную подложку прозрачной, сохраняя тёмный текст
   базового светлого варианта. Отдельное исправление для night-garden не
   распространялось на бордовый шёлк.
3. Сброс `margin: 0` для абзацев оказался специфичнее их смысловых стилей;
   декоративный псевдоэлемент внутри `:is()` не скрывался ожидаемым образом.

## Изменения

- `MaterialGreeting.tsx` задаёт отдельный последовательный поток личного
  поздравления: обращение, вступление, пожелания, заключительные слова.
  Максимальная ширина чтения — 640px; длина строки и акценты абзацев различаются.
  Все исходные абзацы остаются в одном редактируемом поле `greeting`.
- В материальных приглашениях сетка `Greeting` также сбрасывается явно.
- Финальная подложка получает 96% цвета поверхности и подходящий цвет текста
  из одной палитры для любого материала/layout. Само изображение не считается
  достаточной гарантией контраста. Подложка, подпись и ссылка проверяются вместе.
- Вокруг высоких декоративных букв оставлен внутренний запас 8px; межстрочный
  интервал заголовков увеличен до 1.18. Это сохраняет границы текста, не создавая
  чрезмерные промежутки между строками.
- Сохранены тексты, изображения и содержимое четырёх опубликованных снимков.

## Проверка

[До исправления](reading-before/README.md) воспроизводятся колонка и недостаток
контраста. [Промежуточный отчёт](reading-after/README.md) отдельно сохраняет
найденные выступы font metrics; его FAIL не скрыт и не заменён успешным статусом.
Требования к границам текста не ослаблялись.

Итог: **25/25 PASS**, минимальный контраст финального текста **8.07:1**.
Промежутки между абзацами —36–48px. Новых POST/AI-вызовов не было.

Итоговый [браузерный отчёт](reading-final/README.md) и
[численные результаты](reading-final/report.json) проверяют четыре существующие
публикации на 320/390/430/768/1280/1664px и личное поздравление без JavaScript.
Проверяются границы текста относительно viewport и родителя, отсутствие двух
колонок в личном письме, ширина абзацев, реальные промежутки между ними от24px
и контраст финала. Коэффициент рассчитывается по sRGB с консервативной оценкой
просвечивающего изображения; обычный текст требует4.5, крупный3.

Полный suite:71 файл /622 теста. ESLint, TypeScript и production build
`.next-material-reading-accepted` прошли. Safari и физический телефон не проверены.
Автотесты не заменяют просмотр сохранённых снимков полного скролла.

Для воспроизведения проверки без AI-вызовов:

```sh
MATERIAL_READING_ALL=1 \
PLATFORM_QA_BASE_URL=http://127.0.0.1:4315 \
PLATFORM_QA_OUTPUT_DIR=docs/material-studio/reading-recheck \
node --env-file=.env.local scripts/qa-material-reading.mjs
```

Локальный сервер должен использовать сохранённый набор данных
`.platform-data/material-studio-2026-10-23` и указанную текущую сборку.
